# Ilya's Homebrew tap

## OpenCode Status Bar

Your OpenCode agents, at a glance. Native macOS menu-bar companion for OpenCode V2.

```sh
brew install --cask yiaany/tap/opencode-status-bar
open -a "OpenCode Status Bar"
```

**Plugin setup is required.** See [installation and first-launch instructions](https://github.com/yiaany/opencode-status-bar#install). This initial release is ad-hoc signed, not Apple-notarized.

Maintained by [Ilya / @yiaany](https://github.com/yiaany). This is a personal tap, not the official Homebrew cask repository.
